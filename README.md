# site-watch

Запасной сторож сайта. Раз в 10 минут GitHub открывает страницу проверки сайта и пишет владельцу в Telegram, если сайт не отвечает два запуска подряд, и ещё раз, когда сайт поднялся.

Нужен на случай, когда основной сторож на самом сервере молчит, потому что у сервера пропала сеть.

- `watch.py`: проверка и сообщения.
- `test_watch.py`: проверка самого сторожа без интернета (`python3 -I test_watch.py`).
- `.github/workflows/watch.yml`: расписание.
- ветка `state`: память между запусками (`state.json`).

Адрес сайта, его название и ключ бота лежат в секретах репозитория и в журналы не попадают.

Проба: Actions, watch, Run workflow, галочка drill. Придёт одно пробное сообщение.
